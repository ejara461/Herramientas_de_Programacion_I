Clase 3 — Tablas HTML

Repaso: solución al punto 1 del Taller 1 (Clase 2)

El punto 1 pedía: «Reorganice el contenido de su proyecto con al menos cuatro etiquetas semánticas distintas entre: <header>, <nav>, <main>, <article>, <section>, <aside>, <footer>. No elimine ni reescriba el contenido de texto, listas, enlaces o imágenes: solo reorganice la estructura.»

A continuación, un código sugerido de solución, usando únicamente etiquetas vistas hasta el cierre de la Clase 2 (ninguna etiqueta de hoy todavía):

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi proyecto PIA</title>
</head>
<body>

    <header>
        <h1>Nombre del proyecto</h1>
        <nav>
            <ul>
                <li><a href="#inicio">Inicio</a></li>
                <li><a href="#proyecto">Proyecto</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <section>
            <h2>Sobre el proyecto</h2>
            <p>Contenido central y único de la página, tal como estaba antes de reorganizar.</p>
            <img src="img/logo.jpg" alt="Logo del proyecto">
        </section>

        <article>
            <h2>Detalle o funcionalidad</h2>
            <p>Un bloque de contenido independiente y autocontenido dentro de la página.</p>
        </article>

        <aside>
            <h2>Información relacionada</h2>
            <p>Contenido secundario, no imprescindible para entender lo principal.</p>
        </aside>
    </main>

    <footer>
        <p>Institución Educativa María de los Ángeles Cano</p>
    </footer>

</body>
</html>

Este código usa seis etiquetas semánticas (header, nav, main, article, section, aside, footer), cumple el mínimo de cuatro exigido, y conserva la regla de un único <main> con el contenido central de la página.

Errores reales encontrados al revisar el taller

Estos son errores que aparecieron de forma repetida en las entregas. Se presentan sin nombres, agrupados por tipo, para que cada uno revise si los cometió.

  • Confundir <header> con <head>. Varias entregas pusieron <meta charset> y <title> dentro de un <header> en el <body>, en vez de dentro del <head> del documento. Son etiquetas distintas: <head> es la sección de metadatos del documento (no se ve en la página); <header> es un bloque visible de contenido, normalmente el encabezado de la página o de una sección.
  • Etiquetas de contenido dentro de <head>. Se encontraron <img> y <a> dentro de <head>. Dentro de <head> solo van metadatos (<title>, <meta>); ningún contenido visible.
  • Anidar <main> dentro de un encabezado de texto. Ejemplo real: <h1><main>Gestión de Daños</main></h1>. Un elemento de estructura de página (<main>) no va dentro de un elemento de texto (<h1>); es al revés: los títulos van dentro de las secciones.
  • Etiquetas sin cerrar o cierres sueltos. Casos con </header> de más (cerrando algo que ya se había cerrado antes) o con <img ...> sin el > final, lo que rompe el resto del documento.
  • Doctype y codificación mal escritos. <!DOCTYPR html>, <!Doctype html.>, charset="UFF-B", charset="UFT -8". El navegador es tolerante, pero un doctype o un charset mal escrito no cumple su función real.
  • Rutas de archivo de Windows en src. Ejemplos: C:\xampp\htdocs\img\..., D:\Nueva carpeta\.... Esas rutas solo existen en el computador de quien programó; en una página web la ruta debe ser relativa al proyecto (img/logo.jpg).
  • Etiqueta <button> no vista en clase. Aparece en una entrega. Toda etiqueta que no se ha visto en clase se trata como contenido no enseñado, sin importar si el resultado visual es válido.
  • Typos de etiquetas ya vistas. <foother>, <foter>. No son etiquetas nuevas ni cuentan como tales: son errores de escritura de <footer>, y se corrigen con indulgencia.

Nota sobre el uso de mayúsculas: <H1>, <UL>, <LI> funcionan igual que en minúscula porque HTML no distingue mayúsculas de minúsculas en los nombres de etiqueta. Aun así, la convención en todo el curso es escribir las etiquetas siempre en minúscula.

La estructura que toda página HTML5 debe tener

Sin importar el tema de la página, estas etiquetas siempre deben estar presentes y en este orden:

  • <!DOCTYPE html> — declara que el documento es HTML5. Va en la primera línea, sin nada antes.
  • <html lang="es"> — envuelve todo el documento.
  • <head> — sección de metadatos, no visible en la página.
  • <meta charset="UTF-8"> — dentro de <head>, define la codificación de caracteres (tildes, eñes).
  • <title> — dentro de <head>, el texto que aparece en la pestaña del navegador.
  • <body> — todo el contenido visible de la página.

Regla práctica: si al abrir el código de una página no se ven, en ese orden, doctype → html → head (meta + title) → body, la estructura está incompleta, sin importar qué tan bien se vea el contenido dentro.

Tablas HTML

Una tabla organiza datos en filas y columnas. Se usa para datos tabulares reales (listados, horarios, precios), nunca para acomodar el diseño general de una página — eso se resuelve más adelante con CSS.

Etiquetas de tabla

<table> contenedor de toda la tabla.

<thead> agrupa la fila (o filas) de encabezado.

<tbody> agrupa las filas con los datos.

<tr> una fila de la tabla (table row).

<th> una celda de encabezado (table header), texto en negrita y centrado por defecto.

<td> una celda de datos (table data).

Ejemplo: tabla de usuarios de un proyecto

<table>
    <thead>
        <tr>
            <th>Documento</th>
            <th>Nombre</th>
            <th>Rol</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>1001</td>
            <td>Ana Torres</td>
            <td>Administrador</td>
        </tr>
        <tr>
            <td>1002</td>
            <td>Luis Gómez</td>
            <td>Usuario</td>
        </tr>
    </tbody>
</table>

El resultado en el navegador (con estilo básico) se ve así:

DocumentoNombreRol
1001Ana TorresAdministrador
1002Luis GómezUsuario

Errores frecuentes al construir una tabla (adelanto para el taller de hoy)

Código con error

<table>
    <tr>
        <td>Documento</td>
        <td>Nombre</td>
    <tr>
    <tr>
        <td>1001</td>
        <td>Ana</td>
    </tr>
</table>

La primera fila usa <td> para el encabezado (debería ser <th>), no hay <thead> ni <tbody>, y la primera <tr> nunca se cierra.

Código corregido

<table>
    <thead>
        <tr>
            <th>Documento</th>
            <th>Nombre</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>1001</td>
            <td>Ana</td>
        </tr>
    </tbody>
</table>
