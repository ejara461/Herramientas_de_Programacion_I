Guía de estudio para la recuperación

Esta guía resume lo que se vio en el módulo y lo que se evalúa el viernes 20 de noviembre. Los ejemplos son de otro proyecto (una tienda escolar) y distintos a los del examen.

Cómo es el examen (en papel, 3 horas):

  • Bloque HTML: 10 preguntas de selección múltiple. Vale 40 % del examen.
  • Bloque CSS: 10 preguntas de selección múltiple. Vale 40 % del examen.
  • Bloque de código: un solo caso en el que escribe a mano un HTML, un CSS y un poco de JavaScript con if/else. Vale 20 % del examen.

Solo se evalúa lo que se vio en clase. Si usa en el bloque de código una etiqueta o propiedad que no se enseñó, se descuenta 0.3 por cada tipo distinto. Es mejor un código sencillo y propio que uno complicado.

HTML

Estructura de una página

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Tienda escolar</title>
</head>
<body>
    <h1>Tienda escolar</h1>
    <p>Bienvenido.<br>Abrimos a las 7:00 a. m.</p>
</body>
</html>

En head va la información de la página (título, juego de caracteres, enlaces a archivos). En body va todo lo que el usuario ve.

    <thead>
        <tr><th>Producto</th><th>Precio</th></tr>
    </thead>
    <tbody>
        <tr><td>Empanada</td><td>Consulte la lista</td></tr>
    </tbody>
</table>

Formulario

<form>
    <label for="cliente">Cliente</label>
    <input type="text" id="cliente">

    <label for="clave">Contraseña</label>
    <input type="password" id="clave">

    <label for="grado">Grado</label>
    <select id="grado">
        <option>Décimo</option>
        <option>Once</option>
    </select>
</form>

Regla clave: el for del label debe ser igual al id del campo. type="text" muestra lo que se escribe; type="password" lo oculta; type="file" permite escoger un archivo.

Errores frecuentes en HTML

  • Olvidar cerrar una etiqueta (</p>, </li>).
  • Confundir src (imagen) con href (enlace).
  • Poner una imagen sin alt.
  • Poner en head algo que debe ir en body.

CSS

Forma de una regla

selector {
    propiedad: valor;
    otra-propiedad: valor;
}

Cada declaración termina en punto y coma. Las llaves encierran la regla. No se escriben etiquetas HTML dentro del CSS.

Tres formas de aplicar CSS

  • Externa: un archivo .css enlazado con <link rel="stylesheet" href="estilos.css"> dentro de head. Es la forma principal.
  • Embebida: un bloque <style>...</style> en head.
  • En línea: el atributo style="color: red;" en una etiqueta.

Cascada: si dos reglas chocan sobre la misma propiedad, gana el estilo en línea; entre externa y embebida gana la que está más abajo en head; en un mismo archivo gana la última regla.

Selectores

p { color: navy; }            /* elemento: todos los p */
.oferta { color: red; }       /* clase: class="oferta" */
#portada { font-size: 24px; } /* id: id="portada" */
nav a { color: white; }       /* descendiente: enlaces dentro de nav */

Modelo de caja

De adentro hacia afuera: contenido, padding, borde, margin. Todo elemento es una caja con esas cuatro capas.

Flexbox

.tarjetas {
    display: flex;
    flex-wrap: wrap;
}

display: flex; se escribe en el contenedor. Sus hijos se ubican uno al lado del otro, en fila. flex-wrap: wrap; permite que pasen a la línea siguiente si no caben.

Diseño responsivo

<meta name="viewport" content="width=device-width, initial-scale=1.0">
@media (max-width: 600px) {
    .tarjetas { display: block; }
}

La etiqueta viewport hace que la página se ajuste al ancho del dispositivo. La media query aplica sus reglas solo cuando la pantalla mide 600px o menos.

JavaScript

El JavaScript se escribe en un archivo .js y se enlaza al HTML con <script src="script.js"></script>. El resultado de console.log se ve en la consola del navegador (tecla F12).

let producto = "Empanada";
let cantidad = 5;

if (cantidad > 10) {
    console.log("Pedido grande");
} else {
    console.log("Pedido pequeño");
}

if (producto === "Empanada") {
    console.log("Se sirve caliente");
} else {
    console.log("Se sirve frío");
}
  • Variable: un nombre que guarda un valor. Un texto va entre comillas; un número, sin comillas.
  • Comparar: igual (=== o ==), mayor que (>), menor que (<).
  • if/else: si la condición se cumple, se ejecuta el primer bloque; si no, el de else. La condición va entre paréntesis y cada bloque entre llaves.
  • Un solo signo = guarda un valor; para comparar se usan dos o tres.

Cómo responder bien

  • Lea la pregunta completa y las cuatro opciones antes de marcar. Descarte primero las que sabe que están mal.
  • En el bloque de código, escriba en este orden: estructura del HTML, luego el CSS y por último el JavaScript. Revise las comillas, las llaves y los puntos y coma.
  • Use solo lo que se vio en clase. Si duda de una etiqueta o propiedad, no la use.
  • Entregue su propio trabajo. Para el docente, la honestidad pesa más que la perfección.

Responda primero sin mirar; luego abra la respuesta.

  1. ¿Qué atributo lleva la ruta de una imagen y cuál lleva el destino de un enlace?
    Ver respuesta

    src para la imagen y href para el enlace.

  2. Un <label for="correo">: ¿qué debe tener el campo para quedar asociado?
    Ver respuesta

    El mismo valor en su id: id="correo".

  3. ¿Qué etiquetas forman una tabla con encabezado?
    Ver respuesta

    table, thead, tbody, tr, th y td.

  4. ¿Qué diferencia hay entre padding y margin?
    Ver respuesta

    padding es el espacio dentro de la caja, entre el contenido y el borde; margin es el espacio fuera del borde.

  5. Un párrafo tiene style="color: green;" y el archivo CSS dice p { color: red; }. ¿De qué color se ve?
    Ver respuesta

    Verde, porque el estilo en línea gana sobre las demás formas.

  6. ¿Cómo se escribe el selector de la clase destacado y el del id portada?
    Ver respuesta

    .destacado con punto y #portada con numeral.

    console.log("Mayor");

    console.log("Menor");
