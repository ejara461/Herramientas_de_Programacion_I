Clase 4 — Formularios HTML (I)

Repaso: solución al ejercicio de código HTML del Taller de Clase 3

El taller pedía construir, sobre el proyecto PIA, una tabla HTML con datos ficticios, con encabezado (<thead>) y cuerpo (<tbody>) diferenciados, mínimo 3 columnas y mínimo 3 filas de datos.

A continuación, un código sugerido de solución, con datos genéricos (no corresponde al proyecto de ningún estudiante), usando únicamente etiquetas vistas hasta el cierre de la Clase 3:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Inventario de repuestos</title>
</head>
<body>

    <header>
        <h1>Taller de Mantenimiento Central</h1>
    </header>

    <main>
        <section>
            <h2>Inventario de repuestos disponibles</h2>
            <table>
                <thead>
                    <tr>
                        <th>Código</th>
                        <th>Repuesto</th>
                        <th>Cantidad disponible</th>
                    </tr>
                </thead>
                <tbody>
                    <tr>
                        <td>RP-001</td>
                        <td>Filtro de aceite</td>
                        <td>12</td>
                    </tr>
                    <tr>
                        <td>RP-002</td>
                        <td>Correa de distribución</td>
                        <td>5</td>
                    </tr>
                    <tr>
                        <td>RP-003</td>
                        <td>Bomba de agua</td>
                        <td>3</td>
                    </tr>
                </tbody>
            </table>
        </section>
    </main>

    <footer>
        <p>Datos ficticios de ejemplo</p>
    </footer>

</body>
</html>

Este código diferencia claramente encabezado y cuerpo, usa tres columnas consistentes en ambos bloques, y no incluye ninguna etiqueta fuera de lo visto hasta la Clase 3.

Errores comunes que se podrían presentar

Estos son errores esperables al construir este tipo de tabla, no necesariamente los que ocurrieron en las entregas reales de este taller. Revise si alguno aplica a su código antes de continuar.

  • Usar <td> en la fila de encabezado. La primera fila de una tabla, cuando representa los títulos de columna, debe ir con <th>, no con <td>, sin importar si visualmente el resultado parece correcto.
  • No diferenciar <thead> de <tbody>. Colocar todas las filas (encabezado y datos) sueltas dentro de <table>, sin agruparlas en estas dos secciones.
  • Número de columnas distinto entre encabezado y datos. Por ejemplo, un <thead> con tres columnas y una fila de <tbody> con solo dos <td>.
  • Filas <tr> sin cerrar o mal anidadas. Abrir una nueva <tr> sin haber cerrado la anterior rompe la estructura del resto de la tabla.
  • Etiquetas no vistas para dar apariencia a la tabla. Por ejemplo, un <button> para "ver más" o un meta name="viewport" agregado al <head>. Se penalizan según el criterio ya explicado, independiente del resultado visual.
  • Investigación por debajo del mínimo de 120 palabras, o que no responde realmente la pregunta planteada sobre la diferencia entre <thead> y <tbody>.

Formularios HTML: form, input, label

Un formulario permite que el usuario ingrese información en una página. Hoy se construye únicamente la estructura del formulario: sin validación de datos, sin envío real todavía dentro de esta sección de teoría (eso se retoma en el mecanismo de envío del taller).

<form>: el contenedor del formulario

<form> agrupa todos los campos que el usuario va a diligenciar. Todo formulario de este curso debe estar contenido dentro de una etiqueta <form>.

<input>: el campo de entrada

<input> es una etiqueta que no lleva cierre (como <img> o <br>) y cuyo comportamiento cambia según el atributo type. Algunos tipos pertinentes para el proyecto:

type="text" — texto libre de una línea (nombre, descripción corta).

type="email" — dirección de correo.

type="tel" — número de teléfono.

type="number" — valores numéricos.

type="date" — una fecha.

type="checkbox" / type="radio" — selección de opciones.

Para enviar el formulario, use <input type="submit">, no <button>. La etiqueta <button> no se ha visto en clase y sigue fuera de la lista blanca; <input type="submit"> cumple la misma función con una etiqueta ya conocida.

<label>: la etiqueta que describe el campo

<label> asocia un texto descriptivo con un campo de formulario. La asociación se hace con el atributo for del <label>, que debe coincidir exactamente con el id del <input> correspondiente. Esta asociación no es solo estética: permite que, al hacer clic en el texto, el foco pase al campo, y es indispensable para la accesibilidad (lectores de pantalla).

Ejemplo: formulario básico de contacto

<form>
    <label for="nombre">Nombre</label>
    <input type="text" id="nombre" name="nombre">

    <label for="correo">Correo electrónico</label>
    <input type="email" id="correo" name="correo">

    <label for="telefono">Teléfono</label>
    <input type="tel" id="telefono" name="telefono">

    <input type="submit" value="Enviar">
</form>

Errores frecuentes al construir un formulario (adelanto para el taller de hoy)

Código con error

<form>
    <p>Nombre</p>
    <input type="text">

    <p>Correo</p>
    <input type="text">

    <button>Enviar</button>
</form>

Usa <p> en vez de <label> (sin asociación accesible con el campo), no hay id ni for, el campo de correo usa type="text" en vez de type="email", y usa <button>, etiqueta no vista.

Código corregido

<form>
    <label for="nombre">Nombre</label>
    <input type="text" id="nombre" name="nombre">

    <label for="correo">Correo</label>
    <input type="email" id="correo" name="correo">

    <input type="submit" value="Enviar">
</form>
